# Study Management Tracker (Weekly Timetable)

This project is a simple Study Management Tracker built using HTML, CSS, and JavaScript. It allows users to view a complete weekly timetable in a clean and organized format.

## Features

* Display timetable for the entire week
* Simple and user-friendly interface
* Organized layout for better readability
* Built using basic web technologies

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Open the project folder
2. Run the HTML file in a browser
3. View the complete weekly timetable

## Note

This project is created for learning and academic purposes.
